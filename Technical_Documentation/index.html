HTML Basics

HTML provides the structure of web pages using elements like headings, paragraphs, and lists.

Each element is represented by tags enclosed in angle brackets.

Attributes provide additional information about elements.

<p>This is a paragraph</p>

HTML documents start with a doctype declaration.

  • Headings
  • Paragraphs
  • Lists
<h1>Heading</h1>
CSS Styling

CSS controls the presentation of HTML elements.

Selectors target elements to apply styles.

Properties define the visual aspects like color and size.

p { color: blue; }

CSS can be inline, internal, or external.

  • Selectors
  • Properties
  • Values
h1 { font-size: 2em; }
JavaScript Fundamentals

JavaScript adds interactivity to web pages.

Variables store data values.

Functions encapsulate reusable code.

let x = 5;

Events respond to user actions.

  • Variables
  • Functions
  • Events
function greet() { alert("Hello"); }
Responsive Design

Responsive design ensures websites look good on all devices.

Media queries adjust styles based on screen size.

Flexible layouts adapt to different resolutions.

@media (max-width: 600px) { body { font-size: 14px; } }

Images should scale proportionally.

  • Fluid grids
  • Flexible images
  • Media queries
img { max-width: 100%; }
Accessibility

Accessibility ensures websites are usable by everyone.

Semantic HTML improves screen reader support.

Color contrast helps visually impaired users.

<button aria-label="Close">X</button>

Keyboard navigation should be supported.

  • Semantic HTML
  • Alt text
  • Keyboard support
<img src="photo.jpg" alt="Description">
